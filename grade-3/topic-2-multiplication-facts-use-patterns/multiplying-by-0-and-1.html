Rule #1: Multiplying by 1

When you multiply any number by 1, it stays exactly the same.

×1
Any number times 1 stays the same!
5 × 1 = 5

Rule #2: Multiplying by 0

When you multiply any number by 0, the answer is always 0.

×0
Any number times 0 becomes 0!
1 × 0 = 0
