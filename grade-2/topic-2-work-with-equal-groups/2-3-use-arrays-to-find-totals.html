Use Arrays to Find Totals

Topic 2: Work With Equal Groups. Rows, columns and repeated addition, with a warm-up, a whiteboard and four games.

About 60 minutes Standard 2.OA.C.4
Tap a row to count!

3 rows of 5. Tap each row to skip count.

📋

Lesson plan at a glance

Objective

Students write repeated addition equations to match an array, by rows and by columns, and use the equation to find the total. Arrays have up to 5 rows and 5 columns.

Essential question

How can you use arrays to find totals?

Success criteria (kid-friendly)

  • I can tell what a row is and what a column is.
  • I can write an equation like 5 + 5 + 5 = 15 for an array.
  • I can find the total by skip counting or adding.

Materials

  • This page, projected for the class
  • Counters or cubes and a 5 by 5 grid mat for each pair
  • Student whiteboards and markers
  • Student Edition, Lesson 2-3
  • Tablets or computers for the games (optional)

Vocabulary

arrayObjects in equal rows and equal columns.
rowObjects that go across, side to side.
columnObjects that go up and down.
⏱️

Lesson flow

  1. 1

    Warm-up game: Array or Not? 5 min

    Students decide if each picture is an array. This brings back equal groups and gets the words row and column ready.

    Ask: What must be true for objects to make an array? Listen for: equal rows, lined up in columns, no gaps.
  2. 2

    Solve and Share on the whiteboard 10 min

    Pose the problem and let pairs model it before you show any method.

    Problem: Maya puts stickers on a page. She makes 3 rows. Each row has 5 stickers. How many stickers does Maya have in all? Show it with counters, a drawing, or an equation.

    Use the whiteboard tools below. Pick the array tool, set 3 rows and 5 columns, and tap the board. Invite two students to share different ways of finding the total.

  3. 3

    Visual Learning: rows and columns 10 min

    Use the explorer in the Learn section. Show the rows first, then switch to columns for the same array.

    Say: A row goes across. A column goes up and down. This array has 3 rows with 5 in each row, so I write 5 + 5 + 5 = 15. Now I look at columns: 5 columns with 3 in each column, so 3 + 3 + 3 + 3 + 3 = 15. Same array, same total!
  4. 4

    Convince Me! 3 min

    Ask: Can an array have 4 in each row and still have a different total than 4 + 4 + 4? Have partners explain with a drawing. (Yes. If there are 4 rows, the total is 4 + 4 + 4 + 4 = 16.)

  5. 5

    Guided practice: Games 1 and 2 12 min

    Play Game 1 as a whole class with volunteers building on the board. Pairs then play Game 2. Circulate and ask students to point to one row and one column.

  6. 6

    Independent practice: Games 3 and 4 12 min

    Students choose their own pace. Watch for students who add the number of rows and columns (3 + 5 = 8) instead of adding the same number again and again.

  7. 7

    Exit ticket and reflection 8 min

    Use the three questions at the end of the page. Finish with: How can you use an array to find a total?

Watch for these mistakes

  • Mixing up rows and columns. Use arm motions: rows go across, columns go up and down.
  • Adding the numbers of rows and columns (3 + 5) instead of repeated addition (5 + 5 + 5).
  • Counting objects twice or skipping one. Have students mark each row as they count it.
  • Thinking uneven rows still make an array.

Support and challenge

  • Support: Use counters on a 5 by 5 mat. Skip count by 2s and 5s together. Color each row a different color.
  • On level: Write both the row equation and the column equation for each array.
  • Challenge: Make two different arrays that each have 12 in all. Write an equation for each.

Exit ticket and quick check

Students answer on their whiteboards. Open an answer to check.

1. Rows

Write an equation for the rows. Then find the total.

Show answer4 + 4 = 8. The array has 2 rows with 4 in each row.

2. Columns

Write an equation for the columns. Then find the total.

Show answer3 + 3 + 3 + 3 = 12. There are 4 columns with 3 in each column.

3. Tell how

Mia says: "I added 3 + 5 to find the total of 3 rows of 5." What would you tell Mia?

Show answerAdd the number in one row again for each row: 5 + 5 + 5 = 15. Adding the number of rows and columns does not count every object.
Reflect: How can you use an array to find a total? Have students finish: "I look at the rows. I add the number in one row ____ times."
